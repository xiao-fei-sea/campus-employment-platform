## 六、技术架构

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| **前端** | Vue3 + Vite | 组件化开发、快速构建 |
| **UI框架** | Element Plus + Tailwind CSS | 组件库 + 原子化样式 |
| **图表** | ECharts | 数据大屏可视化 |
| **状态管理** | Pinia | Vue3官方推荐 |
| **路由** | Vue Router | SPA路由管理 |
| **后端** | FastAPI | 高性能异步API |
| **ORM** | SQLAlchemy 2.0 | 数据库操作 |
| **认证** | JWT + bcrypt | 令牌+密码加密 |
| **数据库** | MySQL | 主数据存储 |
| **缓存** | Redis | 会话/缓存（未配置时自动降级） |
| **异步任务** | Celery + Redis | 邮件/通知等后台任务 |
| **文件存储** | 本地磁盘 | 简历、头像、Logo、营业执照 |
